# Agent Note: 可离线导出的最小诊断日志

Status: implemented

## Problem

用户退出 Claude 后遇到守护进程存在但核验报告未就绪，现场手机未连接 ADB。只有「运行中」与状态文件不足以区分实际退出、锁等待、桥接失败和旧界面提示。

## Decision

模块持续将固定事件码与进程 ID 写入 root 私有日志，单文件超过 64 KiB 时轮转，保留一份旧日志。日志记录启动、等待与取得防火墙锁、守护就绪及心跳、退出、租约回收和桥接准备；Hook 使用专属 `ClaudePrivacyDiag` 标签记录核验阶段和固定错误类别。

状态卡的「导出诊断日志」启动后壳内的导出 Activity。Activity 将固定 root 命令输出直接写入私有缓存文件，用户通过 Android 文档选择器确认保存位置。导出发生在本机，不请求网络、不自动发送；取消或完成后移除临时文件。日志包含模块和 Hook 版本、守护锁占用、PID/启动时间/cgroup 及精简门禁状态。任何配置原文、实际替身值、完整公网 IP、Cookie、令牌、聊天以及任意异常消息均不进入导出。

Root 事件参数只接受短 ASCII 事件码；Hook 标签同样只写固定码，导出再按格式筛选。原有 `ClaudePrivacyGate` 详细异常标签不参与导出。日志写入使用独立非阻塞锁，避开防火墙锁与监督锁，也避免诊断本身阻塞核验。

界面沿用现有随系统明暗的状态卡和小型次级操作按钮；参考本机 Claude DESIGN 的动作层级，保留项目现有字体与令牌。恢复后旧的 `watchdog_unavailable` 显示为守护已就绪、等待重新核验，保留拒绝状态；回到页面时重读核验状态。

## Alternatives considered

- 让用户继续接 ADB 抓完整日志：现场证据最全面，但用户当前离开电脑；全量日志还包含其他应用的数据。
- WebView Blob 下载：代码较少，SukiSU WebView 的下载处理缺少当前设备验证。使用系统文件选择器显式确定目标文件。
- 导出配置与完整 logcat：便于大范围排查，但会夹带公网 IP、设备替身值及其他应用的数据；仅导出本模块受控事件和必要系统状态。

## Consequences

新增 Hook 导出 Activity，模块升级后需要覆盖更新 Hook。日志记录有少量磁盘写入；Root 双日志总量约 128 KiB，导出只取最近事件。Hook 的专用 logcat 事件随系统日志缓冲轮转，重启后可能丢失，因此建议在恢复或重启前导出。

格式自查覆盖参数限制、敏感字段排除与轮转；移动尺寸页面检查覆盖守护恢复、旧提示消除与导出命令；Android 代码已编译。当前手机未连接，系统文件选择器的目标机保存及守护退出原因仍等待用户导出现场日志验证。
